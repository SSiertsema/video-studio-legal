Privacy Policy

Video Studio

Who this applies to

Video Studio is a self-hosted application used only by its developer to publish videos to channels the developer owns. It does not collect data from the public or from viewers.

What data is accessed

When the channel owner connects an account, Video Studio uses OAuth to obtain access tokens with the minimum permissions needed to:

  • upload videos and set their title, description, tags, language, privacy status and scheduled publish time;
  • read back the uploaded videos' status and basic statistics (views, likes, comments) to verify publication;
  • delete test uploads created by the application itself.

For YouTube this uses the YouTube API Services with the scopes youtube.upload and youtube.force-ssl.

How data is stored

Access and refresh tokens are stored only on the owner's own computer, in a file readable only by that user. Upload records and statistics are kept in a local database on the same computer. Nothing is sent to any server other than the platform APIs themselves.

Sharing

No data is sold, shared with, or transferred to third parties. No analytics, advertising or tracking is used.

Retention and deletion

Data is kept only as long as the channel is connected. Deleting the local credentials file removes all tokens. Access can also be revoked at any time:

  • Google / YouTube: Google security settings
  • Facebook / Instagram: Facebook Settings → Business integrations
  • TikTok: Settings → Security → Manage app permissions

To request deletion of any data, open an issue; all locally stored data will be deleted.

YouTube API Services

Video Studio uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy.
